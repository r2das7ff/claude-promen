Фото изделий для карточек товара.

Отводы: положите файл рядом с именем
  otvod.jpg
Как только файл появится здесь, он автоматически подставится на все страницы
отводов (в блок hero-right над паспортом). Если файла нет — показывается
аккуратная заглушка «Фото изделия готовится».

Рекомендации к файлу:
  - формат: JPG (или PNG), пропорции ~16:10, на светлом/белом фоне;
  - размер: 1200×750 px достаточно, вес до ~300 КБ;
  - имя строго otvod.jpg (нижний регистр).

Другие категории (тройники, переходы, фланцы, крепёж …) пока показывают
заглушку намеренно — фото добавим позже, по одному файлу на категорию.
