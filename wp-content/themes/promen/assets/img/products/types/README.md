# Снимки по типам изделий (черновик, на проверке)

Каталог `products/` даёт снимок по слагу категории WooCommerce. Эти 18 кадров —
уровнем ниже: типы внутри категории, которые сейчас показывают родительский
снимок. Механизма подстановки по типу в теме ещё нет — файлы лежат отдельно и
никуда не подключены, пока не согласованы.

Сгенерировано 2026-09-03 по рецепту из `../README.txt`
(seedream_v5_pro, 1:1, 2k, remove_bg, пять блоков промпта, меняется только первый).
Упаковка: `scripts/pack-product-photos.py` — кроп по альфе, бокс 1200×860, WebP q82.

Тип определяется полем `product_type` в `_promen_dims` (СДТ) либо
`_promen_family` (крепёж).

## Расхождения названий и нормативов (жирным в таблице)

Снимки сделаны по нормативу, а не по подписи в каталоге — подписи в трёх местах
не соответствуют ГОСТ, который стоит в тех же карточках:

* **Б-ФУНД (1561 шт.)** — ГОСТ 22032-76 «Шпильки с ввинчиваемым концом длиной 1d»
  и ГОСТ 22043-76 «Шпильки для деталей с гладкими отверстиями». Это шпильки,
  фундаментных болтов среди них нет. Заголовки товаров («Болт M10х10 … ГОСТ
  22043-76») тоже неверны. Если решим не трогать данные — нужен другой снимок.
* **Г-УМ (24 шт.)** — ГОСТ 5927-70 «Гайки шестигранные класса точности А».
  Уменьшенный размер под ключ — это ГОСТ 15521/15522, их в каталоге нет.
* **Г-ПРОЧ (24 шт.)** — ГОСТ 5929-70 «Гайки шестигранные низкие класса точности А».
  Колпачковых гаек (ГОСТ 11860) в каталоге нет, хотя `_promen_family` пишет
  «колпачковая».

Мелочи того же рода: Б-ВП — это ГОСТ 10602-94, болты диаметром свыше 48 мм, а не
высокопрочные по ГОСТ Р 52644; Ш-УС — ГОСТ 11371-78, обычные шайбы (усиленные —
ГОСТ 6958-78).

## Что переснято после проверки

* **ЗР (5)** — первый вариант снимали с открытого торца: тело вышло шире устья,
  борт пропал, глубина ~0,6D вместо 0,3–0,4D по ГОСТ 17379 (h ≥ 0,25D).
  Пересняли профилем куполом вверх.
* **ББ (7)** — был бочкообразный блок шире, чем выше. По СТО ЦКТИ 530.01
  (рис. 1) бобышка точёная: прямой цилиндр с параллельными стенками и острыми
  кромками, выше, чем шире, плоский торец с фаской 45° у резьбы, снизу
  коническая разделка 50°±2° с притуплением 10±1. Пересняли по чертежу.
* **ШТ (6)** — было два дефекта: буртик (моя выдумка) и стенка ~20 % D.
  По ОСТ 34-42-670-84 «Ответвления штуцерами» (рис. 2, для Dу > 65 мм) штуцер —
  тонкостенная труба постоянного диаметра, нижний торец обработан **седловиной**
  по наружной поверхности основного трубопровода, верхний при S ≥ 4 мм — разделка
  50°±3° с притуплением 2±1 мм (при S₁ ≤ 3,5 мм торец ровный, без разделки).
  Толщина стенки подтверждается данными каталога: 108×4 = 3,7 % D, 159×5 = 3,1 %,
  377×6 = 1,6 %, 32×3,5 = 11 %. Пересняли трижды: без буртика → тоньше стенка →
  с седловиной. Седловину подтверждают два независимых документа — ОСТ 34-42-670-84
  и ОСТ 34.10.761-97. ОСТ 34.10.509-90 (44 из 79 позиций) в архиве по-прежнему нет,
  но это документ той же серии ТЭС, конструкция та же.

* **ДН (8)** — был «гриб»: широкий диск с хвостовиком меньшего диаметра.
  По СТО ЦКТИ 504.01-2009 (рис. 1–3, табл. 1) донышко — толстая точёная пробка
  ОДНОГО наружного диаметра, равного наружному диаметру трубы (133×18 → D=135,
  273×36 → D=278); никакого выступа нет. Сверху фаска 3×45°, сбоку цилиндр,
  снизу по наружной поверхности разделка 35° с притуплением 1±0,5, а в нижнем
  торце расточена цилиндрическая выемка d ≈ 0,72 D, кольцевая стенка s равна
  стенке трубы. H/D от 0,7 у мелких до 0,17 у крупных.
* **ПТ (2)** — форма была верной, а пропорции нет: кадр почти кубический.
  По табл. 1 СТО ЦКТИ 318.01 длина L = 82–105 мм при Dа = 30–76, то есть
  L/Dа = 1,4…2,7. Пересняли вытянутым, L/Dа ≈ 1,6. Кромки 35° с притуплением
  1±0,5, бор конический 20°±2°.

## Близкие пары

* 14 и 17 — обе низкие гайки, различаются только классом точности: 17 чище и
  светлее (точёные поверхности), 14 — со штамповочной коркой.
* 16 — нормальная гайка, форма та же, что на общем `../gayki.webp`; отличается
  чистотой обработки.
* 5 повторяет предмет с `../zaglushki.webp` (эллиптическая заглушка) и ракурс тоже
  близкий. Первый вариант снимали с открытого торца, чтобы развести кадры, — вышел
  брак (тело шире устья, борта нет, глубина ~0,6D вместо 0,3–0,4D по ГОСТ 17379,
  где h ≥ 0,25D). Модель на этом ракурсе стабильно лепит шар или миску, поэтому
  переснято профилем куполом вверх. Если отдельный кадр для ЗР не нужен — строку
  можно закрыть наследованием `../zaglushki.webp`.

## Пересъёмка тройника 10.09.2026

`troyniki-ts-svarnoy-perehodnyy.webp` заменён. Прежний кадр читался как мелкая
точёная деталь: длинный тонкий корпус, штуцер вполовину его диаметра, светлые
обточенные торцы. ОТК прислал образец реального изделия — ОСТ 34 10.764-97 идёт
на Ду150…1600, и там корпус короткий и массивный, длиной примерно в свой
диаметр, а штуцер маленький, около трети, приварен угловым швом по кругу.
Новый кадр снят по этому образцу.

Тон оставлен серии — светлая сталь mill-finish. На фото ОТК деталь тёмная,
в окалине; если решим переводить весь каталог на такой вид, это отдельная
пересъёмка всех 24 кадров, вразнобой они смотреться не будут.
