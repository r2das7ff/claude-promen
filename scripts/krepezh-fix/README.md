# Крепёж: шпильки ГОСТ 22032/22043 лежали в болтах — 23.09.2026

## Что было сломано

1 561 позиция каталога называлась «Болт фундаментный» и лежала в разделе
«Болты». По документам это шпильки:

| Норматив | Официальное название (normatives/registry/normatives_master.csv) | Позиций |
|---|---|---|
| ГОСТ 22032-1976 | Шпильки с ввинчиваемым концом длиной 1d. Класс точности В | 767 |
| ГОСТ 22043-1976 | Шпильки для деталей с гладкими отверстиями. Класс точности А | 794 |

Фундаментный болт — вообще другое изделие (ГОСТ 24379), в каталоге его нет.
Ошибка была видна снабженцу с первого взгляда: в разделе «Болты» лежали
шпильки, а в коде изделия стояло «-Б-».

## Что правится

| Поле | Было | Стало |
|---|---|---|
| Раздел | `bolty` | `shpilki` |
| Семейство (`_promen_family`) | Болт фундаментный | Шпилька с ввинчиваемым концом · Шпилька для гладких отверстий |
| Заголовок | Болт M2.5х10 10.9 ГОСТ 22032-76 | Шпилька M2.5х10 10.9 ГОСТ 22032-76 |
| Название в реестре | Болт M2.5×10 10.9 | Шпилька M2.5×10 10.9 |
| Артикул | 22032-**Б**-2.5-10-10.9 | 22032-**ШП**-2.5-10-10.9 |
| Адрес | /catalog/krepezh/**bolty/bolt**-m2-5h10-… | /catalog/krepezh/**shpilki/shpilka**-m2-5h10-… |

Название в реестре собирается из семейства (`promen_fastener_kind`), поэтому
правка меты сама меняет и его, и подпись под названием.

## Как запускать

```
wp eval-file scripts/krepezh-fix/fix.php dry     # прогон, ничего не пишет
wp eval-file scripts/krepezh-fix/fix.php apply   # запись + пересборка канона
python scripts/krepezh-fix/build_map.py          # карта 301 из moves.tsv
```

`fix.php` пишет `moves.tsv` (старый путь → новый), `build_map.py` собирает из
него и из `scripts/otk-fix/moves.tsv` карту
`wp-content/mu-plugins/promen-catalog-moves-map.php` — плагин переездов отдаёт
по старым адресам 301.

После `apply` на сервере: сброс кеша страниц (`wp promen cache-purge`).
Meilisearch переиндексировать не нужно — на проде его нет, каталог читает
канон напрямую. Локально: `wp promen search-reindex`.

## Результат локального прогона

- Болты: 4 598 → 3 037 позиций, Шпильки: 1 778 → 3 339
- 1 561 переезд в карте 301, старый адрес отвечает 301 на новый
- Дублей названий в разделе стало меньше: шпильки 3 339 строк / 3 016 названий
  (остаток — типоразмеры, совпадающие по разным ГОСТам, см. отдельную задачу
  про норматив в названии)

## Что осталось

Подписи «Болт с уменьшенной головкой» (ГОСТ 7805/7808) и «Болт с шестигранной
головкой» (7795/7796/7798) формально верны, но не различают классы точности
А и В — один типоразмер повторяется под пятью ГОСТами с одинаковым названием.
Лечится не переименованием, а нормативом в названии изделия.
