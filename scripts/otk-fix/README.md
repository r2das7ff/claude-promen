# Правки каталога по замечаниям ОТК — 10.09.2026

Специалист ОТК прислал пять замечаний по карточкам СДТ. Все подтвердились, за
ними нашлись два системных дефекта, из-за которых точечная правка карточек
ничего бы не дала.

## Что было сломано

**1. Норматив не соответствовал изделию.** Карточка ссылалась на ОСТ, изданный
на другую деталь: ОСТ 24.125.22-89 (бобышки) и 24.125.23-89 (пробки) выдавались
за заглушки, ОСТ 34-10-428-90 (заглушки фланцевые) — за эллиптические приварные,
ОСТ 34 10.764-97 (тройники **переходные**) — за равнопроходные, ОСТ 34-10-423-90
(переходы **точёные**) шёл с фото штампованного перехода.

**2. Описание собиралось по категории, а не по изделию.** Всё, что лежало в
«Заглушках», получало текст «Заглушка эллиптическая бесшовная приварная по …» —
включая бобышки, штуцеры и фланцевые заглушки. Отсюда «БОБЫШКА ИСП. … Заглушка
эллиптическая».

**3. Тема дорисовывала второй торец.** `promen_ensure_both_pipe_ends()`
дублировала D×s, когда второй конец не заполнен, и ставила `equal_pass = да`.
Так недозаполненная строка превращалась в «переход 23×3-23×3» — а переход
равнопроходным не бывает. Правка одних данных этого не пережила бы: пара
рисовалась заново на каждом рендере.

**4. Фото подбиралось только по слагу категории.** Пять разных предметов в
«Заглушках» получали один снимок эллиптического колпака.

**5. Латентный фатал в теме.** `promen_dn_is_standard()` вызывалась из
`promen_sanitize_dims()`, но не была определена нигде. Спасал короткий цикл
(`$turned || …`), поэтому на сайте она почти не срабатывала. Вскрылась массовым
обновлением карточек.

## Что сделано

| Файл | Что |
|---|---|
| `norm_products.tsv` | карта норматив → изделие, 56 позиций; источники: содержания сборников, титулы PDF, паспорта на docs.cntd.ru |
| `fix.php` | правит заголовок, описание, слаг, код типа и размеры в базе; `dry` — прогон, `apply` — запись |
| `build_repairs.py` | разбор слагов и сведение Ду↔Dн (вспомогательный, для анализа) |
| `needs-size.tsv` | 91 позиция, которым второй типоразмер нужно проставить руками по таблице норматива |
| `../../wp-content/mu-plugins/promen-catalog-moves.php` | 301 для сменившихся слагов, 410 для удалённых |
| `inc/product-data.php` | карта норматив→изделие, подбор фото по типу, запрет дорисовки второго торца, определена `promen_dn_is_standard()` |

Запуск:

```
docker compose run --rm wpcli eval-file /scripts/otk-fix/fix.php dry
docker compose run --rm wpcli eval-file /scripts/otk-fix/fix.php apply
```

Скрипт идемпотентен: повторный прогон меняет только то, что ещё не приведено в
порядок.

## Результат

* 739 карточек с исправленным описанием, 29 сменили слаг (со 301), 3 удалены
* «Заглушка эллиптическая» у бобышек, пробок, штуцеров и фланцевых заглушек — 0
* физически невозможных размеров (стенка ≥ D/2) — 0
* ложной равнопроходности под нормативами на переходные изделия — 0
* товаров 15 391 (было 15 394), карта сайта сходится

## Что осталось

* **91 позиция ждёт второго типоразмера** — `needs-size.tsv`. Восстановить
  механически нельзя: в слагах второй элемент записан то наружным диаметром, то
  условным проходом, и часть слагов несёт тот же самый диаметр в двух видах.
  Нужна таблица ОСТ 34 10.764-97 (52 страницы, скан) — либо ввод руками, либо
  отдельный заход с разбором таблицы.
* **10 нормативов не подтверждены** — перечислены в конце `norm_products.tsv`.
  Документов нет ни в архиве, ни в открытом доступе; карточки под ними не трогали.
* **Категория для штуцеров, бобышек и пробок.** Они по-прежнему лежат в
  «Заглушках», и это видно в URL. Разводить по своим категориям — отдельное
  решение: меняется структура каталога, меню и фасеты.
