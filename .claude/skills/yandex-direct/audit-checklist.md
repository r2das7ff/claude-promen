# Чеклист аудита кампании

44 пункта, которые печатает `scripts/ads/direct_audit.py`. Ниже — что
каждый означает и какое значение считать нормальным для промышленного B2B
с длинным циклом сделки.

Скрипт помечает стрелкой строки, где кампании расходятся между собой.
Расхождение не всегда ошибка, но всегда повод объяснить, почему так.

## Кампания: деньги и показы

| Пункт | Норма | Чем плохо отклонение |
|---|---|---|
| Состояние | `OFF/DRAFT` до запуска | `MODERATION` — ждёт проверки, `ACCEPTED` — уже тратит |
| Стратегия | поиск и сети раздельно, сети выключены у поисковых | смешанные показы не разделить в отчётах |
| Недельный лимит | 2 000–5 000 ₽ на кампанию | это потолок, а не план: без него стратегия разгоняется |
| **Потолок ставки** | 60–90 ₽ от фактического CPC | **без потолка `HIGHEST_POSITION` берёт клики по 99 ₽** |
| Дневной бюджет | не нужен при недельном лимите | дублирование ограничений мешает стратегии |
| Часовой пояс | по месту завода | московский сдвигает отчёты и расписание на 2 часа |
| Расписание | круглосуточно | форма работает ночью; резать часы без статистики рано |
| Регионы групп | 225 (Россия) или уже | пустое поле = показы везде, включая нецелевое |

## Кампания: структура

| Пункт | Норма | Чем плохо отклонение |
|---|---|---|
| Групп | 4–35 | 800 групп по одной фразе не наберут статистики |
| Фраз | 5–200 на группу | больше 200 Директ не примет |
| Автотаргетинг-записей | по одной на группу | это не ключи; при подсчёте семантики вычитать |
| Объявлений | не меньше числа групп | группа без объявления не показывается |
| Фраз «мало показов» | 0 | `RARELY_SERVED` — фраза не участвует в аукционе |
| Ставки на фразах | заданы | при автостратегии не используются, но не мешают |

## Кампания: отсечения

| Пункт | Норма | Чем плохо отклонение |
|---|---|---|
| Минус-слов | 80–400 | пусто — значит платите за «работу», «бесплатно», «б у» |
| Общий стоп-лист | подключён | иначе правку списка надо повторять в каждой кампании |
| Запрещённых площадок | 1 000 у сетевых, 0 у поисковых | у РСЯ без списка треть бюджета уходит в приложения |
| Заблокированных IP | адреса офиса | свои заходы тратят бюджет и портят статистику |
| **Автотаргетинг** | `EXACT` и `ALTERNATIVE` | **все пять категорий = слив на смежные запросы** |

## Кампания: аналитика

| Пункт | Норма | Чем плохо отклонение |
|---|---|---|
| Счётчики | сайт + профиль организации | без счётчика организации звонки не привяжутся |
| **Метка для Метрики** | `YES` | **без `yclid` сделку из CRM не связать с кликом** |
| Ключевые цели | заданы | при «максимум кликов» стоит системная цель Директа |
| Атрибуция | `AUTO` | для длинного цикла подходит, фиксированная режет окно |
| Организация | заполнена | адрес и телефон в объявлении, нужна для коллтрекинга |
| Номер коллтрекинга | подставляется сам | проверять после запуска |
| Уведомления | включены | иначе не узнаете об остановке |

## Кампания: настройки

| Пункт | Норма | Чем плохо отклонение |
|---|---|---|
| Мониторинг сайта | `YES` | при падении сайта показы не остановятся сами |
| **Приоритет по фразе** | `YES` при точной структуре | **иначе покажется объявление с лучшим CTR, а не с точной посадочной** |
| Альтернативные тексты | `YES`, но проверять | нейросеть искажает номера ГОСТ и марки стали |
| Область интересов | `YES` | на поиске не влияет |
| Корректировки | возраст и устройства | 18–24 в B2B дают нулевую конверсию |
| Перенос бюджета | вместе с пакетной стратегией | — |
| Пакетная стратегия | после 10 конверсий в неделю | поодиночке кампании не обучатся |

## Объявления

| Пункт | Норма | Чем плохо отклонение |
|---|---|---|
| Заголовок 2 | всегда `None` | это нормально: Директ склеивает его в первый |
| Быстрые ссылки | у всех, тематические | общий набор ведёт мимо нужного раздела |
| Уточнения | 4 штуки | бесплатная площадь объявления |
| Организация в объявлении | у всех | адрес, телефон и рейтинг в выдаче |
| Отображаемая ссылка | у всех | видимый «хвост» адреса, поднимает релевантность |
| Изображение | у сетевых | **в РСЯ без картинки объявление почти не показывается** |
| Видео, Кнопка | опционально | кнопка «Запросить КП» стоит теста |
| Визитка | не нужна | заменена организацией |
| Турбо-страница | не нужна | есть сайт |

## Что проверять руками, аудит не покажет

1. **Заявки против глубины визита.** Если из сетей идут «конверсии» при
   глубине ровно 1,0 и 20–30 секундах — это не заявки. Метрика,
   отчёт по площадкам.
2. **Есть ли товар под запросы.** Фасет раздела должен содержать норматив
   или марку, иначе человек придёт и не найдёт.
3. **Работают ли посадочные.** Открывать в браузере: серверный HTML
   счётчик фасета не меняет.
4. **Что нагенерили альтернативные тексты** — после модерации.
5. **CRM-цели.** Если по ним ноль достижений за год во всех кампаниях —
   офлайн-конверсии не работают, конверсионные стратегии включать нельзя.
