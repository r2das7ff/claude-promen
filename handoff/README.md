# PROM-EN WordPress — хендофф-пакет

**Для кого:** разработчик, который развернёт проект локально и продолжит
полную миграцию сайта (все страницы) на WordPress.

| Файл | Что это |
|------|---------|
| **[HANDOFF.md](./HANDOFF.md)** | Главная инструкция: развёртывание, архитектура, CLI, что сделано / что дальше |
| `wordpress-db.sql.gz` | Свежий дамп MariaDB (каталог + контент на момент сборки) |
| `MANIFEST.txt` | Состав архива и версии |

Архив всего проекта: см. `promen-wp-handoff-*.tar.gz` рядом с этой папкой
или в родительском каталоге `PROM-EN/`.

Сайт после `docker compose up`: **http://localhost:8080**
